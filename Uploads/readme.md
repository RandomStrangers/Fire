Looking for the files to run Flames? 
You can download the required files from here. You need these files:
Flames.exe, FlamesCLI.exe, Flames_.dll

The dev build is a special form of Flames being developed to have backwards compatibility with the other cores: 
[RandomStrangers, ](https://github.com/RandomStrangers/RandomStrangers)
[SuperNova, ](https://github.com/RandomStrangers/SuperNova)
[DeadNova, ](https://github.com/RandomStrangers/DeadNova)
[Sparkie,](https://github.com/RandomStrangers/Sparkie) and 
[Sparks.](https://github.com/GoldenSparks/Sparks) 
<sup>Sparkie and Sparks are the same core, but are based on different versions of [MCGalaxy.](https://github.com/ClassiCube/MCGalaxy)</sup>
Plugins made for these cores will only work if you use the dev build, they will not work with the normal version.
